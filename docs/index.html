Search Ranking Signal Analysis & Position Prediction

Author: Muhammad Zain ul Abideen | Machine Learning Engineering Intern

Abstract: This research paper investigates the structural relationship between query-level engagement signals (clicks, impressions, baseline CTR) and organic search engine result positions. Using a 10,000-row warehouse sample from Search Console and Analytics data, we engineered features including log-transformed impressions and interaction density. We evaluated four machine learning regression models (Random Forest, Gradient Boosting, Linear Regression, and Ridge) to predict average search placement. Gradient Boosting achieved the best performance with an RMSE of 4.12 and R² of 0.78, outperforming linear baselines. These results provide an automated decision-support framework to prioritize content updates for underperforming web pages.

1. Introduction & Problem Statement

Managing large-scale enterprise content portfolios requires operational clarity on which pages suffer from visibility degradation. Manual evaluation across thousands of URLs is inefficient. This capstone provides an objective, data-driven system to model expected search positioning relative to observed click-through rates and impressions, identifying high-potential pages needing content updates.

2. Data Pipeline & Contract

Data was ingested directly from the FlyRank warehouse via DuckDB, joining fact_content_query_90d with dim_content over a 90-day aggregation window. To prevent data leakage, future performance deltas and outcome labels were strictly excluded prior to model execution.

3. Feature Engineering & Methodology

We engineered three core predictors from raw search performance metrics:

  • log_impressions: Natural log transformation (np.log1p) to normalize skewed search impression distributions.
  • baseline_ctr: Calculated ratio of clicks to impressions (safe handling for zero-division).
  • interaction_density: Interaction feature compounding total clicks with log-impression volume.

The dataset was split into an 80% training set and a 20% validation set with fixed random seeds for reproducibility.

4. Experimental Results & Leaderboard

Four regression models were trained and evaluated on the identical validation split:

5. Actionable Recommendations

  1. Focus on High Interaction Density: Pages with high log_impressions but sub-baseline CTR represent immediate refresh opportunities.
  2. Automate Refresh Priority: Use the Gradient Boosting model's residual rankings to auto-generate weekly editorial revision queues.

6. Limitations & Honest Framing

This study presents observed and directional associations between search engagement metrics and search ranking placement. It does not claim causal proof of Google's proprietary search algorithm, nor does it guarantee ranking increases following content edits.
